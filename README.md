# Web Scraping api

A simple Node.js API for scraping text or content from web pages using Axios and Cheerio.

## Getting Started

Run the following commands to install all dependencies using `pnpm`:

```bash
pnpm add express
```

```bash
pnpm add axios
```

```bash
pnpm add cheerio
```

```bash
pnpm add cors
```
